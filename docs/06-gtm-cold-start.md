# 06 · GTM & Cold Start

**Status:** Draft v0.1 · **Last updated:** 2026-10-03

## 1. Bottom line
This is a single-sided product (unlike LaborLink), so cold start is a **trust problem, not a liquidity problem**. Users must hand a PII-heavy PDF to a new product. The GTM plan is built around earning that trust in person first, then scaling it through proof (public evals, open methodology, shareable report cards).

## 2. Stages
| Stage | Users | Channel | Goal |
|---|---|---|---|
| 0 · Dogfood | Shivam + family portfolios | — | Golden set, find parse and logic bugs |
| 1 · Concierge | First 20 | Personal network, ex-colleagues (Zomato, Apna Mart, Onsurity), IIT Kanpur alumni | Watch people use it; run user interviews (T-3); set baselines |
| 2 · Closed pilot | 20–100 | Invite links; finance communities (Reddit r/IndiaInvestments, Twitter/X fintwit, LinkedIn); posts on how we built it | Measure the metrics framework; test the growth loop |
| 3 · Open beta | 100+ | Content + referral loop | Only if kill criteria are not hit |

## 3. Trust levers (ranked by expected impact; hypotheses)
1. **Show the math everywhere.** Every number is auditable.
2. **Privacy proof.** Password never stored, PDF auto-deleted, one-tap delete, "AI never sees your name or PAN", stated plainly on the upload screen.
3. **Public methodology + eval scorecard** in the repo.
4. **No-sales pledge.** We don't sell funds; there are no affiliate links.
5. **Founder-led.** Real name, LinkedIn and the build log in public.

## 4. Growth loop (to test in Stage 2)
`Upload → shareable anonymised "report card" (e.g. "my portfolio has 3 overlapping funds, ₹X/yr in avoidable costs") → friend clicks → lands on "check yours in 3 minutes" → upload`
Risk: people may not share money details. Test with a share-rate metric; drop it if share rate is negligible.

## 5. Content engine (low cost, compounding)
- "Build in public" posts: weekly learnings on CAS parsing, evals, regulation. This doubles as AI PM portfolio content.
- Teardown posts: "What 30 real portfolios taught me about overlap" (aggregated, anonymised, with consent).

## 6. Pricing during pilot
Free. Pricing tests are deferred (D-OPEN-5). We'll run a willingness-to-pay question in interviews (Van Westendorp-style) at the end of the pilot.

## 7. What we will not do
Paid acquisition, finfluencer paid promotions (SEBI has restricted regulated entities' association with unregistered finfluencers; ⚠ check the current rule before any partnership), or promises of returns.
